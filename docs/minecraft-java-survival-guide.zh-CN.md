# 我的世界 Java 版详细生存指南 从主世界到击败末影龙

适用于 Minecraft Java 版原版普通生存，面向第一次通关的玩家，以稳妥推进为主，结合 Java 版 26.3 环境。物资数量按单人计算，文中的“1 组”通常指 64 个。

完整路线是：

**主世界建立基地 → 获得铁装备、弓和钻石镐 → 建下界传送门 → 下界要塞获取烈焰棒和下界疣 → 收集末影珍珠、制作药水 → 末影之眼寻找主世界要塞 → 激活末地传送门 → 拆水晶 → 击败末影龙。**

注意区分两个地方：**下界要塞在下界，主要找烈焰人；末地传送门所在的要塞在主世界。**

## 主世界起步与基地建设

### 第 1 步 完成木器到石器的升级

第一个白天主要做三件事：获得工具、找到食物、准备过夜。

1. 观察附近环境，优先寻找树木、水源、动物和裸露的石头。
2. 徒手砍下约 **16 个原木**，先把一部分做成木板。
3. 制作工作台、木棍和一把木镐。
4. 用木镐挖圆石，先收集约 **32 个**。
5. 制作石镐、石斧、石剑和熔炉。

常用配方可以直接在工作台的配方书中查看：

| 物品 | 主要材料 |
|---|---|
| 工作台 | 4 木板 |
| 木棍 ×4 | 2 木板 |
| 石镐 | 3 圆石、2 木棍 |
| 石斧 | 3 圆石、2 木棍 |
| 石剑 | 2 圆石、1 木棍 |
| 熔炉 | 8 圆石 |

保留一些原木，后面可以烧木炭。木器用来过渡即可，得到石器后就可以开始采煤、采铁。

**完成条件：有石器、熔炉，以及备用木材。**

### 第 2 步 解决食物和第一个夜晚

白天尽量收集 **10～20 份可食用物资**，优先把牛肉、猪肉、羊肉等烧熟。

如果找到村庄，可以利用床、农田和干草块。干草块能分解成小麦，3 个小麦能合成面包。留下一些种子和动物，方便后续建立稳定食物来源。

准备照明：

1. 找到煤矿，用镐采集煤。
2. 找不到煤时，用熔炉把原木烧成木炭。
3. 1 个煤或木炭加 1 根木棍，可以合成 4 根火把。

过夜有两种办法：

- **有普通床：**在安全位置放床，晚上睡觉，并确认重生点已经设置。
- **没有床：**天黑前挖一个小型山洞，或搭一个有屋顶的临时房间，封住入口并插火把。

普通床需要 **3 个同色羊毛、3 个木板**。找到铁后，可以制作剪刀剪羊毛，方便保留羊继续产毛。

**26.3 新增的草床不能设置重生点，而且使用后会消失。基地和末地入口前要使用普通床。**这一点见[官方 26.3 更新说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3)。

**完成条件：有能安全过夜的地方，最好已经设置普通床重生点。**

### 第 3 步 建立能够持续补给的基地

基地先满足实用需求。位置尽量靠近树木、水源和适合种地的平地。

依次放好：

1. 普通床。
2. 工作台。
3. 两个熔炉。
4. 两三个箱子。
5. 足够的火把。
6. 能关闭的入口。

记下基地坐标。Java 版通常按 `F3` 查看坐标，部分 Mac 键盘需要 `Fn + F3`。

随后建立食物来源：

- **小麦田：**打草获得种子，用锄头耕地，在水边播种。
- **牛羊圈：**用小麦引诱牛羊进围栏，喂两只成年动物繁殖。
- **鸡圈：**用小麦种子等引诱和繁殖鸡，之后可以获得羽毛制作箭。
- **甘蔗：**发现后带回，种在水边，后面做纸和书。
- **树木：**补种树苗，保证木材供应。

出远门前，把本次用不到的矿物、钻石和其他贵重物品存进箱子。家里最好留一套简单工具和一些食物。

**完成条件：有固定基地、备用物资，以及持续产出的食物。**

### 第 4 步 进入铁器阶段并准备盾牌和水桶

先从浅层洞穴、山体裸露矿脉采铁。铁矿石需要至少使用石镐开采，粗铁放进熔炉烧成铁锭。

新手可以优先探索容易退出的小洞穴；如果选择挖矿道，`Y≈16` 附近是常用的找铁高度之一。

第一批铁建议这样分配：

1. **盾牌：1 铁锭、6 木板。**
2. **水桶：3 铁锭。**
3. **铁镐：3 铁锭。**
4. 铁胸甲、铁护腿。
5. 铁头盔、铁靴。
6. 铁剑和备用工具。

一套完整装备的大致用量：

| 装备 | 铁锭数量 |
|---|---:|
| 全套铁甲 | 24 |
| 铁镐 | 3 |
| 铁剑 | 2 |
| 铁斧 | 3 |
| 水桶 | 3 |
| 盾牌 | 1 |
| 合计 | **36** |

再留一些备用铁，准备 **40～48 个铁锭**会比较方便。

盾牌装备在副手，面对骷髅等敌人时举盾防御。Java 版近战有攻击冷却，等攻击指示恢复再挥剑，通常比连续乱点更有效。

水桶装满后放在快捷栏，可以帮助你：

- 熄灭身上的火。
- 从高处沿水流下降。
- 处理部分岩浆。
- 阻挡或驱赶末影人。

挖矿时遵守这些习惯：

- 向下走楼梯矿道，避免直接挖脚下。
- 矿道插火把，并用统一规则标记回程。
- 挖开矿物前留意其后方和下方是否有岩浆。
- 血量不足、食物快用完、工具快损坏时返回。
- 早期遇到深暗之域、幽匿尖啸体时绕开，避免招来监守者。

**完成条件：全套铁甲、盾牌、铁镐、铁剑、装满水的桶，以及足够食物。**

### 第 5 步 准备钻石镐弓箭和基础附魔

接下来收集钻石和远程武器。

钻石可以从深层矿道或洞穴获得：

- `Y≈-58～-59` 是常见的深层找钻石高度，但岩浆风险较高。
- 新手可以先在 **脚部坐标 `Y≈-53`** 附近挖水平矿道，再逐步向更深处探索。
- 开采钻石至少使用铁镐。

钻石优先分配：

1. **前 3 个做钻石镐**，用于挖黑曜石。
2. 如果再找到 2 个，可以准备制作附魔台。
3. 多余钻石可以做钻石剑、胸甲或护腿。

接着准备弓箭：

- 弓：3 根木棍、3 根线。
- 箭 ×4：1 燧石、1 木棍、1 羽毛。
- 燧石通常通过挖砂砾获得。
- 线可以从蜘蛛等来源获得。
- 羽毛主要来自鸡。

进入下界前，建议有 **一把弓和至少 64 支箭**。

附魔是提高容错率的好办法。附魔台需要 **2 钻石、4 黑曜石、1 本书**，还要准备青金石和经验。

优先考虑：

| 装备 | 实用附魔 |
|---|---|
| 护甲 | 保护 |
| 靴子 | 摔落缓冲 |
| 剑 | 锋利；抢夺方便收集材料 |
| 弓 | 力量 |
| 工具 | 效率、耐久 |

满级附魔通常需要 15 个有效书架，以及玩家达到 30 级。书架和附魔台之间留一格空隙，别用火把等物品堵住这层空间。初期也可以先使用低等级附魔。

**完成条件：有钻石镐、弓箭，最好已有基础附魔。**

## 建造传送门与探索下界

### 第 6 步 建造下界传送门

这条路线采用比较直观的办法：**钻石镐挖黑曜石，再搭传送门。**

1. 找到岩浆源，通常可以在岩浆池附近找到。
2. 从安全位置放水，让水流接触岩浆源，形成黑曜石。
3. 用钻石镐挖掘。
4. 采集时防止黑曜石下面还有岩浆，掉落物可能被烧毁。

最小下界门需要 **10 个黑曜石**，门洞内部宽 2 格、高 3 格。四个角可以省略：

```text
.OO.
O..O
O..O
O..O
.OO.
```

其中 `O` 是黑曜石，`.` 是留空位置。

最后用打火石点燃门洞内部。打火石需要 **1 铁锭、1 燧石**。

如果准备同时制作附魔台，总共采 **14 个黑曜石**比较方便。注意，**哭泣的黑曜石不能替代普通黑曜石构成下界门。**

在门附近放补给箱，并记下主世界一侧的坐标。

### 第 7 步 整理第一次下界探险的装备

建议按下面准备：

| 物品 | 建议数量或要求 |
|---|---|
| 护甲 | 铁甲，另穿戴一件金甲 |
| 金靴 | 1 双，通常比较省黄金 |
| 盾牌 | 1 面，耐久充足 |
| 铁剑或钻石剑 | 1 把 |
| 镐 | 主用、备用各 1 把 |
| 弓和箭 | 弓 1 把，箭至少 64 支 |
| 熟食 | 32～64 份 |
| 圆石等建筑方块 | 至少 3 组 |
| 原木 | 16 个左右 |
| 打火石 | 1 个 |
| 火把 | 32～64 根 |
| 金锭 | 可选，用于猪灵交易 |

金甲必须**穿在身上**。手里拿金剑或背包里放金锭，不能起到相同作用。

下界里要记住：

- 水不能像在主世界那样放出来灭火。
- 普通床在下界使用会爆炸。
- 岩浆流动快，靠近边缘时保持距离。
- 门可能被恶魂火球炸灭，因此带上打火石。
- 圆石比下界岩更适合做入口保护屋和暴露在外的通道。

第一次进入下界，可以先做一个短途行动：**确认出生环境、保护传送门，然后回主世界检查补给。**

### 第 8 步 保护下界入口并寻找下界要塞

进入下界后：

1. 先观察脚下和四周，确认没有紧邻岩浆或悬崖。
2. 记下下界门坐标。
3. 用圆石围一个带屋顶的小保护屋。
4. 留出可进出的门洞。
5. 在安全位置存一些食物、方块和备用工具。

随后开始探索，每经过明显岔路就做路标。路标最好能看出回门方向，例如用圆石搭小箭头，或把火把统一放在前进方向的右侧。

主世界与下界的 **X、Z 水平距离大致为 8∶1**，但 Y 高度不能直接按这个比例换算。初次探索仍应以实际路线和坐标为准。

你要找的是：

- 深暗红色下界砖建筑。
- 长桥、走廊、立柱和楼梯。
- 可能出现烈焰人、凋灵骷髅。

大面积黑石、猪灵聚集的建筑通常是**堡垒遗迹**。首次通关可以先绕开，里面的猪灵蛮兵很危险。

普通猪灵在你穿金甲时通常不会主动攻击，但**开箱子、挖金矿或攻击猪灵仍可能激怒它们**。金甲也不能让猪灵蛮兵变友好。这些普通猪灵行为可参见[官方猪灵介绍](https://www.minecraft.net/en-us/article/meet-piglins)。

探索时还要避免误伤僵尸猪灵，否则容易引来群体追击。

**完成条件：找到下界要塞，并保留清楚的返回路线。**

## 获取下界材料与建立酿药点

### 第 9 步 取得烈焰棒下界疣和灵魂沙

下界要塞的核心目标是：

| 材料 | 建议最终储备 | 用途 |
|---|---:|---|
| 烈焰棒 | **约 16 根** | 末影之眼、酿造台、酿药燃料 |
| 下界疣 | 8 个以上 | 制作粗制药水、回家种植 |
| 灵魂沙 | 4～8 个以上 | 种下界疣 |

**烈焰人的稳妥打法：**

1. 先在附近建一个能退入的掩体，用完整方块挡住射线。
2. 用弓攻击单个烈焰人，避免同时引来一群。
3. 面对火球时举盾，利用墙角躲避。
4. 对方一轮攻击结束后，再寻找射击或近战机会。
5. 残血、着火、周围怪物增加时，马上退回掩体。
6. 击杀后确认烈焰棒已经实际捡进背包。

烈焰人刷怪笼可以保留，方便以后补材料；少量火把不能可靠地让它停刷。

遇到凋灵骷髅，可以利用**净高只有两格**的通道阻挡它们，再隔着入口攻击。不过烈焰人仍能通过这种空间，需要另外用墙和拐角防御。

下界疣常见于要塞内部部分楼梯旁的灵魂沙地块。收集时带回疣和灵魂沙，之后在主世界就能种植。

**不必第一次就拿满 16 根棒。**如果已经拿到几根烈焰棒和下界疣，可以先回家制药，再带抗火药水回来补足。

16 根棒的分配示例是：

- 留 1 根做酿造台。
- 其余 15 根能合成 30 个烈焰粉。
- 其中 20 个用于制作 20 颗末影之眼。
- 剩下的用于酿药燃料、力量药水等。

烈焰粉同时承担寻路材料和酿造燃料的作用，见[官方烈焰粉介绍](https://www.minecraft.net/en-us/article/taking-inventory--blaze-powder)。

### 第 10 步 回主世界建立酿药点

把重要材料安全带回基地，再进行下一阶段准备。

1. 用 **1 烈焰棒、3 圆石**制作酿造台。
2. 用玻璃制作玻璃瓶。
3. 对水源使用玻璃瓶，获得水瓶。
4. 在酿造台燃料位置放烈焰粉。
5. 下方放水瓶，上方先放下界疣，得到**粗制药水**。
6. 再加入对应材料，制作效果药水。

一次可以同时处理 3 瓶药水，尽量一起酿制。

| 药水 | 从粗制药水开始加入 | 后续加入红石粉 | 主要用途 |
|---|---|---|---|
| 抗火药水 | 岩浆膏 | 延长为 8 分钟 | 下界火焰、岩浆危险 |
| 缓降药水 | 幻翼膜 | 延长为 4 分钟 | 末地高空坠落 |
| 力量药水 | 烈焰粉 | 延长为 8 分钟 | 提高近战伤害 |

岩浆膏可以从岩浆怪获得，也能用黏液球和烈焰粉合成。抗火药水能防火和岩浆伤害，**不能防普通近战攻击、凋零效果或末影龙龙息**。

缓降药水需要幻翼膜。通常在连续至少三个游戏日未休息后，主世界夜晚可能出现幻翼；在安全露天区域猎杀它们获得膜，之后再恢复正常睡觉。幻翼膜可以将粗制药水变成缓降药水，见[官方幻翼膜介绍](https://www.minecraft.net/en-us/article/taking-inventory--phantom-membrane)；红石延长型持续 4 分钟，见[缓降药水资料](https://minecraft.wiki/w/Potion_of_Slow_Falling)。

准备屠龙时，缓降药水很值得投入。它能给你更多时间调整落点，但掉进虚空仍然会死。

## 收集末影珍珠与寻找主世界要塞

### 第 11 步 收集末影珍珠并准备末影之眼

建议先以 **24～28 颗末影珍珠**为目标：

- 约 20 颗计划用于末影之眼。
- 其余保留为传送珍珠。
- 如果要塞很远或寻路损耗较大，继续追加。

珍珠有三种实用来源。

**方法一：击杀末影人**

适合在主世界开阔地区，或已经找到的下界诡异森林进行。

1. 先搭一个**内部净高两格、顶棚足够宽**的小棚。
2. 站进棚内，确认自己有后退空间。
3. 只招惹一只末影人。
4. 等它靠近后，用剑攻击。
5. 保持在棚内，别追出去，也别站在边缘。

末影人比两格高，无法像玩家一样走进这种空间。在主世界还可以用水帮助防御。

**方法二：与牧师村民交易**

如果已经有村庄，可以培养牧师，查看较高等级交易中是否出售末影珍珠。

- 酿造台是牧师的工作站。
- 可以通过交易逐步升级。
- 以实际解锁的交易列表为准。
- 找到卖珍珠的牧师后，可以持续用绿宝石购买，等待补货。

这条路线比较适合已经有村民和绿宝石来源的基地。

**方法三：与成年普通猪灵以物易物**

穿金甲，把金锭交给成年普通猪灵，它会随机返还物品，其中可能有末影珍珠和抗火药水。

交易结果随机，**不要把“一组金锭一定换够珍珠”当作计划前提**。缺少的部分可以通过末影人或村民补齐。

珍珠的这些来源，以及与烈焰粉合成末影之眼的用途，可参见[官方末影珍珠介绍](https://www.minecraft.net/en-us/article/ender-pearl)。

配方是：

**1 末影珍珠 + 1 烈焰粉 → 1 末影之眼。**

不要把所有珍珠都合成眼，留一些原始珍珠供末地应急使用。

### 第 12 步 用末影之眼寻找主世界要塞

带上食物、床、工具、水桶、火把和末影之眼，从主世界开始寻找。

1. 在开阔地使用一颗末影之眼。
2. 看清它飞向哪个方向。
3. 等它落下，尽量捡回来。
4. 朝这个方向走约 **200～400 格**，再投一次。
5. 接近目标后缩短间隔，每隔几十格确认一次。
6. 当眼开始往回飞，或明显往地下钻，说明已经接近目标区域。

每次投掷都有 **20% 概率破碎**；传送门最多还要用 12 颗眼，因此要留出寻路损耗，见[末影之眼机制](https://minecraft.wiki/w/Eye_of_Ender)。

找到大致位置后：

1. 在地表做明显路标，并记下坐标。
2. 挖楼梯向下，不要直接挖脚下。
3. 遇到石砖、苔石砖、裂纹石砖和人工走廊后，进入要塞。
4. 每走过一个岔路就标记，封住已经检查过的死路。
5. 寻找有熔岩、蠹虫刷怪笼和绿色传送门框架的房间。

**末影之眼指向要塞的定位区域，不会直接把你带到传送门房间。**进入后还需要搜索走廊。

如果传送门框架因世界生成问题严重缺损，生存模式无法自行合成框架修复，通常需要寻找另一个要塞。

**完成条件：找到末地传送门房间，并建立安全到达路线。**

## 末地战前整备与重生点设置

### 第 13 步 完成最后一次装备整备

第一次通关，建议使用下面这份配置：

| 物品 | 推荐准备 |
|---|---|
| 护甲 | 状态良好的附魔铁套或钻石装备 |
| 靴子附魔 | 尽量有摔落缓冲 |
| 剑 | 铁剑或钻石剑，最好有锋利 |
| 弓 | 最好有力量附魔，耐久充足 |
| 箭 | 128 支左右；无限弓也要带至少 1 支普通箭 |
| 镐 | 1 把，耐久充足 |
| 盾牌 | 1 面 |
| 水桶 | 2 桶 |
| 建筑方块 | 至少 3 组，进入后还可挖末地石补充 |
| 优质熟食 | 约 64 份 |
| 金苹果 | 有条件准备 2～4 个 |
| 缓降药水 | 3～6 瓶，尽量为 4 分钟型 |
| 力量药水 | 可选，1～2 瓶 |
| 末影珍珠 | 留 4～8 颗应急 |
| 雕刻南瓜 | 可选 |
| 空玻璃瓶 | 可选，用于收集龙息 |

雕刻南瓜需要戴在头上，才能防止因直视末影人而激怒它们；主动攻击仍会招来反击。它会遮挡视野，也占用头盔位置，可以根据习惯选择。

建议固定快捷栏，例如：

`剑｜弓｜镐｜方块｜水桶｜食物｜缓降药水｜珍珠｜金苹果`

盾牌放副手。先在主世界练习切换水桶、方块和食物，避免战斗时找不到物品。

### 第 14 步 保护传送门房间并设置近距离重生点

进入末地之前，在主世界要塞里做好补给点：

1. 清理房间内的敌人。
2. 处理蠹虫刷怪笼，初次通关可以直接挖掉。
3. 在不影响门框的前提下，把容易掉进去的熔岩坑安全封住。
4. 在附近安全房间放**普通床**。
5. 使用床，确认提示已经设置重生点。
6. 留出床边重生空间。
7. 放一个补给箱，存备用食物、武器、方块和药水。

床留在这里，别随身拆走。这样普通生存死亡后，可以较快重新进入末地。

随后给所有空缺的传送门框架装上末影之眼；12 个框架全部有眼后，中央会出现黑色的传送门面。

**普通床只能在这里的主世界使用，不能带进末地当作睡觉工具。**

进门前检查：

- 血量和饥饿值已补满。
- 装备耐久充足。
- 缓降药水、水桶和方块已放快捷栏。
- 备用物资已经留在箱子里。

第一次进去时，可以在跳入前喝一瓶缓降药水。

## 进入末地与末影龙战斗

### 第 15 步 进入末地后先安全登上主岛

进入末地通常出现在一块黑曜石平台上。平台可能在岛内，也可能在主岛外。

如果平台在岛内：

1. 观察四周。
2. 用镐挖通往地表的安全阶梯。
3. 不要直接向上把头顶整片挖开。

如果平台在岛外：

1. 确认主岛方向。
2. 潜行搭桥，尽快连接主岛。
3. 尽量把桥加宽，必要时加侧边保护。
4. 保持视线偏低，避免直视末影人。
5. 留意末影龙飞近，潜行也挡不住撞击和击退。

登岛后先做两件事：

- 挖一些**末地石**，用于通道、落脚平台和临时掩体。
- 在远离岛边、远离中央祭坛的位置，准备一个净高两格的临时避难棚。

末地石比普通圆石更适合这里，因为末影龙能破坏许多普通建筑方块。掩体主要帮助处理末影人，仍然要躲避龙息。

### 第 16 步 摧毁黑曜石柱上的末地水晶

末地中央通常有 **10 根黑曜石柱，每根顶部有一个末地水晶**。其中两个水晶有铁栏杆保护。

水晶会给龙回血，所以先处理水晶，再集中输出末影龙。

**先处理裸露水晶：**

1. 在地面找能看到水晶的位置。
2. 拉满弓，略微抬高瞄准，考虑箭的下坠。
3. 逐个射爆。
4. 记住处理过的柱子，别反复射击空柱。
5. 看到龙息火球落向自己时，先移动离开，再继续瞄准。

尽量利用地面射击，减少爬柱子的次数。

**再处理有铁栏杆的水晶：**

1. 先确认缓降效果仍有足够时间。
2. 尝试从地面合适角度寻找可以命中的空隙。
3. 如果无法命中，用末地石沿柱侧搭建带落脚平台的上升路线。
4. 接近围栏侧面，挖开可射击的缺口。
5. 后退到与水晶保持十几格距离的安全射击位置，必要时增设完整方块掩护。
6. 再用弓引爆水晶。
7. 沿路线或水流下降，别在药效快结束时直接跳。

**不要站在水晶旁边用剑砍。**爆炸可能直接杀死你，即使有缓降也挡不住爆炸伤害。

拆完后观察：如果还有治疗光束连接水晶和龙，就继续寻找遗漏的水晶。

### 第 17 步 按飞行用弓落地用剑的节奏打龙

清完水晶后，战斗分成两个阶段。

**龙在空中飞行时：**

1. 尽量活动在岛中央区域，远离虚空边缘。
2. 保持移动，观察龙的飞行方向。
3. 用弓瞄准龙头前方，适当预判。
4. 龙靠近冲撞时，优先躲避。
5. 紫色龙息区域出现后，立即横向离开。

**龙停在中央基岩祭坛时：**

1. 观察龙头在哪一侧。
2. 避开地面的紫色龙息。
3. 从头部一侧接近，用剑攻击龙头。
4. 等攻击冷却恢复后再挥剑。
5. 看到龙准备起飞时，撤出身体附近。

Java 版末影龙栖息在中央祭坛时，**箭无法造成正常伤害，应改用近战攻击**，见[官方末影龙攻略](https://www.minecraft.net/en-us/article/ender-dragon)。

第一次打可以只在落地时输出，空中主要负责躲避、吃食物和补药。这样耗时更长，但容易控制节奏。

战斗过程中，优先顺序是：

**离开危险区域 → 恢复血量 → 补缓降 → 再继续攻击。**

### 第 18 步 遇到意外时按情况处理

| 情况 | 立即处理 |
|---|---|
| 被末影人追打 | 低头，跑向两格高掩体；在地面放水帮助脱离 |
| 被龙打飞 | 有缓降时调整落点，尽量回到岛内，远离虚空 |
| 没有缓降而坠落 | 朝有效地面落点准备水桶；有珍珠时尽早瞄准岛内安全位置 |
| 站进紫色龙息 | 立即横向离开，在干净地面吃食物或治疗 |
| 血量很低 | 停止输出，远离龙和末影人，补血后再回战场 |
| 缓降快结束 | 回到地面补药，再进行高处操作 |
| 箭用完 | 保持生存，等待龙落地后近战 |
| 装备或补给严重不足 | 利用已有物资保命，别再冒险爬柱或靠近岛边 |

这里有几个容易误解的地方：

- **缓降防摔落，不能防虚空死亡。**
- **水桶需要有合适的方块或落点，无法凭空在虚空中造水救命。**
- **末影珍珠必须命中合适位置才有用，而且传送会造成伤害。**
- **抗火药水不能防龙息。**
- **牛奶会清掉缓降、力量等正面效果，别在高处随手喝。**
- **盾牌不能代替躲避龙息。**

如果在普通生存中死亡：

1. 从要塞补给点重生。
2. 带上食物、武器和方块再进入。
3. 尽快寻找仍然留在地面的装备。
4. 原版掉落物在区块加载时通常约 5 分钟后消失；多人服务器里可能始终有人加载末地。
5. 掉进虚空的装备无法靠普通捡取找回。

## 击败末影龙与返回主世界

### 第 19 步 确认击杀收集奖励并返回主世界

当龙的生命值归零后：

1. 等待死亡动画结束。
2. 收集掉落的经验。
3. 确认中央返回传送门已经开启。
4. 通过中央传送门返回主世界，首次会显示终末之诗和制作人员名单。

首次击杀后还会出现龙蛋。想带走时可以：

1. 先确保附近没有容易掉入的洞口。
2. 轻点龙蛋，让它瞬移到附近位置。
3. 找到龙蛋，保持它的直接支撑方块不动。
4. 在该支撑方块正下方挖出空间，放好火把。
5. 再挖掉支撑方块，让龙蛋落到火把上，变成可拾取物品。

**末影龙死亡、返回传送门开启，就已经完成这次生存通关目标。**龙蛋和龙息可以在确保安全后再收集。
